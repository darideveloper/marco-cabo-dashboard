## Why

No version-controlled API client exists for `marco-cabo-dashboard`. Developers must reconstruct `curl` from `project/urls.py:13-42`, `travels/views.py`, and `travels/serializers.py:6` to test `GET /api/hotels|postal-codes|vehicles|service-types|pricing` and `Sales` flows (`/api/sales/`, `/api/sales/done/`). The reusable Bruno blueprint at `/home/daridev/Desktop/obsidian/daridev/20-areas/work/django/django-bruno.md` exists but has not been applied here. A workspace that mirrors endpoints 1:1 and embeds expected responses in `docs {}` blocks lets developers explore APIs in the Bruno UI without reading source, and keeps error contracts (`400`/`401` from `utils/handlers.py:4` and `travels/views.py`) visible without running requests. `POST /api/sales/` now carries optional `vip_code` tracking-only (`travels/models.py:170` FK `VipCode` `PROTECT`, `serializers.py:66-89` `trim + iexact + active=True → 401`) exposed as `vip_code: value|null` on `GET /api/sales/?stripe_code=` (`views.py:83`) with no pricing bypass.
